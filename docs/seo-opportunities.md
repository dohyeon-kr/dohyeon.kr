# SEO opportunity workflow

The Ghost dashboard SEO section uses Search Console query aggregates to surface a short list of search terms worth reviewing first.

The ranking is intentionally heuristic, not a search-ranking score or guarantee. It combines impressions, average position, and CTR to suggest one of three editorial actions:

- improve the SEO title and search description when a query already ranks near page one but CTR is weak;
- strengthen the article body and internal links when a query sits roughly in positions 4–20;
- consider a dedicated article when a query receives meaningful impressions but remains beyond position 20.

Search Console currently returns query-level aggregates in this dashboard, so confirm the query's landing page in Search Console before editing a post.

Public posts also render up to three newer related posts that share the current post's primary tag. The current post is excluded. This provides contextual internal links without changing article copy.
