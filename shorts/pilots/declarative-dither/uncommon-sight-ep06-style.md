# uncommon_sight · 철학 릴스 EP.06 스타일 회고 / 후속 제작 기준

> 2026-11-11 「만족한 돼지와 불만족한 소크라테스」 공개본 사용자 피드백. **현재 디더링 분위기는 유지**하고, **도식의 설명력과 정교함은 높인다.** 영상 재게시나 기존 인스타그램 게시물 수정 지시가 아니다.

- 공개본: https://www.instagram.com/uncommon_sight/reel/Dfl54iqB1io/
- 주제: 존 스튜어트 밀의 『공리주의』를 물길 비유로 풀어낸 약 52초 릴스.
- 평가: **전반적으로 좋음. 특히 모노크롬 동적 디더링의 질감·분위기는 유지할 가치가 큼.** 가장 큰 개선점은 **도식화가 지나치게 단순함**.
- 실제 공개본은 브라우저 Canvas 기반 모션과 음성 합성/MP4 인코딩으로 제작했다. 이 문서는 **미래 HyperFrames/숏츠 제작의 스타일 참조**이며, 기존 HyperFrames 자동 컴파일러에 같은 효과가 구현됐다는 뜻이 아니다.

## 고정할 시각 정체성 (유지)

1. **차콜 블랙 + 백색 타이포 + 회색 계조**: 거의 검정에 가까운 배경, 낮은 채도의 은은한 광원/그라데이션, 섬세한 선과 점. 네온, 과한 색상, 장식적 글로우, 강한 UI 카드 색상은 피한다.
2. **움직이는 명암에 반응하는 디더링**: 단순한 도트 이미지의 이동/확대가 아니라, 시간에 따라 변하는 원본 형태·광원·명암·알파를 매 프레임 Bayer ordered dithering으로 재양자화한다. 움직이는 그라데이션에서 도트 밀도가 자연스럽게 달라지는 느낌이 핵심. 구현·결정성 검증은 [dynamic-dithering.md](dynamic-dithering.md)를 따른다.
3. **명확한 큰 한글 타이포**: 화면의 주제 문장 1개를 중심으로, 얇은 구획선·작은 영문 메타·짧은 보조 문구로 위계를 만든다. 설명 텍스트와 작은 라벨은 디더링 처리하지 않고 선명하게 남긴다. 글자·상자·선이 서로 침범하지 않게 실측한다.
4. **차분한 에디토리얼 모션**: 입자·곡선·물길이 유기적으로 변하지만 과도한 바운스, 랜덤 깜박임, 산만한 카메라 이동은 피한다. 서사상 의미 있는 변화만 사용한다.
5. **불규칙하되 설계된 라벨 위치**: '사랑 / 이해 / 창조 / 관계' 같은 단어를 일렬 또는 완벽한 그리드에 반복 배치하지 않는다. 시각적으로 자연스럽게 흩어지되 **시드가 고정된 결정적 배치**와 텍스트 충돌·안전영역 검사를 통과해야 한다. 진짜 무작위 프레임 점프는 금지.
6. **풀블리드 9:16 커버**: 검은 레터박스/내부 3:4 포스터를 9:16에 끼워 넣지 않는다. 영상·커버 모두 실제 화면을 꽉 채운다. 프로필 4:5 중앙 크롭에서도 제목이 보이도록 별도 프리뷰를 확인한다.
7. **내용 우선**: 시청자가 이해해야 하는 핵심 주장과 예시를 화면으로 번역한다. 불필요한 메타 설명, 논증을 가로막는 별도 '비유/원래 논증' 비교 카드, 시각적 효과만을 위한 장면은 넣지 않는다.

## 개선할 부분: 도식화의 설명 밀도

**문제:** 이번 릴스의 원형 게이지, 몇 개의 단순 막대, 대칭 원, 한 점에서 퍼지는 선만으로는 '돼지의 물길 몇 개'와 '인간의 다양한 물길', '채워진 정도와 다양성의 차이'를 충분히 보여주지 못했다. 질감은 좋지만 **관계·변화·결과가 빈약한 도식**이었다.

**다음 제작에서 바꿀 것:**

- **도식마다 한 가지 질문에 답한다.** 예: '무엇이 몇 개 있는가?', '어느 경로가 채워졌는가?', '완전한 충족과 풍부한 경험이 어떻게 다른가?' 도식이 답하지 못하면 그래픽을 삭제하거나 재설계한다.
- **데이터/관계의 구조를 보여준다.** 단순한 원 2개보다 **실제 흐름의 시작점 → 분기 → 도착점**, 연결선 두께/밝기/흐름 속도, 일부 미완성 경로를 함께 보여준다. 항목 수를 비교하는 장면과 충족률을 비교하는 장면을 분리하되 자연스럽게 모핑해 연결한다.
- **공간적 서사를 만든다.** '돼지'는 적은 수의 굵고 짧은 경로가 빠르게 채워지고, '인간'은 더 많은 길이 여러 방향으로 뻗어 일부만 흐르는 구조로 보여준다. **같은 기준에서 차이를 읽을 수 있는** 공통 시작점·기준선·시간축 중 하나를 사용한다.
- **정적인 도형 교체 대신 상태 변화**를 표현한다. 물이 차오름 → 새로운 가지가 열림 → 서로 다른 끝점으로 흘러감 → 일부는 비어 있음 → 그럼에도 여러 곳에서 빛/움직임이 발생하는 연속 장면을 선호한다.
- **도식의 디테일을 높인다.** 주경로와 보조경로, 간격의 리듬, 곡률의 차이, 경로 간 위계, 드문 교차점, 미세한 흐름 입자, 계조·디더링 밀도 변화를 사용한다. 다만 복잡성은 **설명력을 높일 때만** 추가한다.
- **'선의 개수만 많아지는 것'을 고도화로 착각하지 않는다.** 인지 가능한 그룹, 의미 있는 라벨, 비교 기준, 핵심 경로 강조, 시간에 따른 상태 변화가 있어야 한다.
- **도식과 라벨은 상호 설명한다.** 단어를 흩뿌리기만 하지 않고 각 라벨을 해당 흐름/종착점에 느슨하게 정렬하거나 짧은 가이드선으로 연결한다. 무작위 배치처럼 보이되 무엇을 가리키는지는 분명해야 한다.
- **반복 도식 지양**: 원형 게이지 → 또 다른 원형 게이지 → 단순 막대의 패턴을 피하고, 같은 의미 구조를 2~3개의 연결된 시점(전체 구조 / 경로 확대 / 상태 변화)으로 보여준다.

### 후속 물길 장면의 권장 연출

| 장면의 의미 | 개선된 도식 |
| --- | --- |
| 돼지의 높은 만족 | 3~4개 경로가 공통 공급원에서 분기, 순차적으로 빠르게 끝점까지 채워짐. 충족의 쉬움을 **진행 과정**으로 보여줌 |
| 인간의 다양한 행복 | 수십 개 경로를 의미별 묶음으로 확장. 서로 다른 곡률·길이·밝기와 부분적으로만 채워진 흐름, '사랑·배움·이해·창조' 등의 선명한 끝점 라벨 |
| 충족률과 경험의 다양성 | 같은 기준으로 두 네트워크를 비교. 돼지는 소수 경로가 전부 밝고, 인간은 다수 경로의 일부가 활성화된 상태. **100% 대 부분 충족**과 **경험의 종류**가 동시에 읽혀야 함 |
| 질문으로 회수 | 네트워크가 정리되며 두 선택지가 대비. 관객의 선택을 묻고 설명을 과잉 덧붙이지 않음 |

> 이 표는 이 주제의 예시다. 다른 철학 주제에 물길/네트워크를 억지로 적용하지 않는다. **주제의 의미 관계에 맞는 정교한 도식**을 새로 설계한다.

## 장면·카피·게시 기준

- 철학자 주장의 핵심을 짧고 정확하게 소개하고, **쉽게 이해할 수 있는 비유와 열린 질문**으로 연결한다. 이번 영상의 방향은 '밀의 쾌락에는 양뿐 아니라 질이 있다 → 돼지/인간의 물길 비유 → 당신은 어느 쪽?'이었다.
- 요청받지 않은 과도한 논증 분해, '이건 밀의 논거가 아니다' 같은 방어적 문구, 무의미한 비교 카드를 자동으로 넣지 않는다. 다만 비유를 철학자의 실제 문장처럼 잘못 인용하지는 않는다.
- 최종 질문이 영상의 정점. 만족한 돼지 vs 불만족한 소크라테스 중 선택을 강요하지 않고 열린 질문으로 마무리한다.
- 설명형 인스타그램 캡션은 시청자가 논지를 따라갈 수 있도록 간결하게 작성한다.
- 기존 릴스는 사용자가 직접 커버를 수정했다. **재게시/삭제/커버 교체를 자동 실행하지 않는다.** 게시 행동은 별도 명시적 요청이 있을 때만 한다.
