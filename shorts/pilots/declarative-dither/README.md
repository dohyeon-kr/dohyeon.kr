# Declarative Dither · Pilot v1

**파일럿:** 2026-11-09 「권한에 맞는 책임감」, DOHYEON KR / 조직·자기계발 릴스.

이 폴더는 파일럿의 **재사용 가능한 스타일·모션·안전영역 계약**을 보존한다. 아직 `src/templates/registry.ts`에 등록된 Remotion/HyperFrames 프로덕션 템플릿이 아니며, `pilot-spec.json`은 렌더러가 읽는 `candidate-XX.json`이 아니다.

## 다음 릴스에서도 유지할 원칙

- **선언형 장면에 선택적으로 사용:** 질문·관점 전환·핵심 결론에만 디더링을 쓰고, 근거 설명은 기존 정교한 도식/사진을 활용한다. 매 장면을 추상 그래픽으로 채우지 않는다.
- **상단 60% 추상도형:** 모노크롬 검정 바탕, 입체감 있는 구체/도넛/분기 형태, 성긴 8×8 Bayer ordered dithering. 파일럿의 도트 간격은 720px 기준 약 10.3px, 1080px 환산 약 15.45px.
- **유한하고 결정적인 움직임:** blob → ring → branch → sphere를 의미에 따라 변형한다. 카메라에 완만한 팬/줌과 절제된 스프링을 쓸 수 있으나, 텍스트는 움직이는 도형과 분리해서 선명하고 안정적으로 유지한다. 독립 난수 깜박임이나 무한 루프 금지.
- **정보성 서사:** 질문 → 맥락 → 대비 → 전환 → 결론 회수. `~합니다/~입니다` 자연스러운 한국어, 장면당 하나의 역할, 실제 TTS 음성 타임스탬프로 컷/자막 타이밍을 맞춘다.
- **커버:** 결론을 선공개하지 않는다. 파일럿 질문 `내 책임은 어디까지일까요?`를 중앙 그리드에서 읽을 수 있게 배치한다. 브랜드 장식은 크롭 밖에 있어도 무방하다.
- **공통 CTA:** 본문 결론을 마친 후 기존 프로덕션 파이프라인에서 별도 삽입한다. 파일럿에 CTA가 없다는 이유로 본문 결론을 없애지 않는다.

## 안전영역 (1080×1920 기준, 절대 픽셀)

| 영역 | 좌측 x | 상단 y | 우측 x | 하단 y |
| --- | ---: | ---: | ---: | ---: |
| 릴스 중요 자막·헤드라인 | 96 | 270 | 920 | 1530 |
| 상부 디더링 스테이지 | 96 | 320 | 984 | 1110 |
| 커버 4:5 프로필 중앙 크롭 | 0 | 285 | 1080 | 1635 |
| 커버 중요 타이포 | 96 | 365 | 920 | 1560 |

배경/디더링 아트는 풀블리드 허용. **중요 텍스트와 의미 있는 라벨만 안전영역 내부를 강제**한다. 경계선 SVG와 색상 가이드는 디버그 프리뷰 전용이며, 게시용 영상/커버에는 굽지 않는다.

> 인스타그램 기기·버전·UI 변화에 대응하기 위한 보수적 제작 기준이다. 공식 플랫폼 보장 수치는 아니므로 실제 릴스 앱에서 최종 점검한다.

## 체크

```bash
node shorts/pilots/declarative-dither/check-safe-area.mjs --self-test
node shorts/pilots/declarative-dither/check-safe-area.mjs --write-guides
```

`pilot-layout.json`은 이 파일럿의 **9개 장면 제목/보조 자막 측정 영역 및 커버 중요 텍스트 3개 측정 영역**을 1080px 좌표로 저장한 스냅샷이다. 새 영상은 새 타이포 실측값으로 갱신해야 한다. 단일 측정 검사는 모든 모션 중간 프레임이나 플랫폼 UI를 자동 검증하지 않는다.

실제 완성 전에는 긴 한글 문장, 전환의 초기/중간/종료 프레임, 휴대폰 크롭, 전체 오디오 트랙의 재생 여부를 확인한다. 로컬 파일럿 영상은 720×1280·30fps로 출력했지만, 프로덕션 정식 릴스는 기존 1080×1920·30fps 정책을 따른다.

기존 `style.safeArea = "shorts-reels"`을 유지한 채 이 검수 프로필을 사용한다. **렌더러·템플릿 레지스트리·워크플로우 옵션·테스트를 함께 구현하기 전에는 새 template ID를 등록하지 않는다.**
