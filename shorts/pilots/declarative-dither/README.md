# Declarative Dither — 파일럿 v1

기준 릴스: **권한에 맞는 책임감** · 조직/자기계발 · 2026-11-09

> 이 파일은 제작 레퍼런스다. 아직 Remotion / HyperFrames 실행 템플릿으로 등록된 것은 아니다. 실제 등록 시 `shorts/src/templates/registry.ts`, 렌더러, 워크플로 선택지 및 검증 테스트를 같이 변경한다.

## 사용 의도

- **선언형 장면**(질문, 전환, 통찰, 결론)에 주로 사용한다. 구체적인 기술/조직 구조 설명이 필요하면 기존 도식 장면을 사용한다.
- 거의 검은 배경, 흰 타이포, 넓은 간격의 점(ordered dither)으로 표현한 추상도형.
- 상단 약 60%를 추상 구체·링·갈라지는 입자에 할당한다. 나레이션을 전달하는 자막/본문은 별도의 정적인 레이어에 배치한다.
- 8×8 Bayer ordered dither, 결정적 seed, 1080 기준 약 15.45px 점 그리드 간격(파일럿 720 기준 10.3px).
- 유한한 의미 기반 morph(압축 → 분기 → 수렴), 절제된 카메라 팬/줌과 스프링. 무작위 깜박임, 무한 루프, 텍스트 과잉 모션 금지.
- 시작은 질문/모순, 중간은 충분한 논거와 선택지, 끝은 질문 회수. 지침 `shorts/docs/narration-style.md`가 우선한다. 완결된 결론 뒤 공통 CTA 별도.

## 나레이션 및 음질 기준 — 파일럿 회고

최초 파일럿은 **원본 음성을 합성하는 과정에서 임시 음원을 약 6.5kbps Opus로 압축**해 심한 품질 열화가 발생했다. 최종 MP4를 AAC 128kbps로 재인코딩해도 중간 압축에서 잃은 정보는 복구되지 않는다.

**필수 품질 게이트:**

1. TTS 원본 WAV/PCM 또는 원본 API 음원을 우선 사용하고 캐시한다. 불필요한 재압축을 하지 않는다.
2. 음성 전달 과정에서 손실 압축이 불가피하다면 **Opus 최소 96kbps, 파일럿 권장 128kbps 이상**으로 유지한다. 6.5kbps 같은 초저비트레이트 중간 음원은 실패 처리한다.
3. 최종 배포 MP4에는 오디오 트랙을 직접 포함하고 **AAC 160kbps 이상(권장 192kbps), 48kHz**로 인코딩한다. 원본 모노 음성을 의미 없이 스테레오로 확장하지 않는다.
4. `ffprobe`로 포맷/샘플레이트/트랙 유무/길이를 확인한다. `ffmpeg`로 처음·중간·끝 음성을 실제 디코드해 무음/깨짐/클리핑 여부를 듣고 검수한다. 메타데이터 검증만으로 음질 합격을 선언하지 않는다.
5. 영상 끝의 음성 잘림을 방지한다. 오디오 시작 오프셋과 자막/씬 전환 타이밍을 실제 음성 길이에 맞추고 부족한 끝 부분은 짧은 무음 패딩으로 채운다. 보이스오버가 영상보다 길면 실패 처리한다.
6. 게시용 결과물은 **단일 MP4**다. 무음 GIF, 외부 음성 URL이 필요한 HTML 플레이어로 대체하지 않는다.

파일럿 기준: 영상 34.5초 / 720×1280 / 30fps, 내레이션 원본 약 33.6초·48kHz 모노 WAV. 수정본은 전달 중간 음원 128kbps Opus → 최종 오디오 약 189kbps AAC 48kHz 모노이며, **원본 WAV를 직접 복사한 무손실 경로는 아니다**.

검증 예:

```bash
ffprobe -v error -show_entries stream=codec_name,codec_type,bit_rate,sample_rate,channels -show_entries format=duration -of json final.mp4
ffmpeg -v error -i final.mp4 -map 0:a:0 -t 5 -f null -
```

## 파일럿의 서사/화면 메타데이터

- 0–2.75s: 질문. “내 책임은 어디까지일까요?” — soft blob
- 2.75–5.76s: 맥락. “동의하지 않는 결정도 있습니다.” — compressed blob
- 5.76–11.08s: 대비. “모든 결과가 내 책임일까요?” — compression
- 11.08–13.6s: 전환. “하지만 선택권은 남아 있습니다.” — torus morph
- 13.6–17.83s: 선택지. 의견을 말하고, 기회로 바꾸기 — ring
- 17.83–21.22s: 다른 환경을 선택하기 — branching
- 21.22–27.1s: 견딜지, 벗어날지 — branching
- 27.1–30.08s: 바꿀 수 없는 결과 내려놓기 — return morph
- 30.08–34.5s: 내 권한 안의 선택에 책임지기 — stable sphere
