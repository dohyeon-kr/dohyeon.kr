# Declarative Dither · Pilot v1

**파일럿:** 2026-11-09 「권한에 맞는 책임감」, DOHYEON KR / 조직·자기계발 릴스.

이 폴더는 파일럿의 **재사용 가능한 스타일·모션·안전영역 계약**을 보존한다. 아직 `src/templates/registry.ts`에 등록된 Remotion/HyperFrames 프로덕션 템플릿이 아니며, `pilot-spec.json`은 렌더러가 읽는 `candidate-XX.json`이 아니다.

## 다음 릴스에서도 유지할 원칙

- **선언형 장면에 선택적으로 사용:** 질문·관점 전환·핵심 결론에만 디더링을 쓰고, 근거 설명은 기존 정교한 도식/사진을 활용한다. 매 장면을 추상 그래픽으로 채우지 않는다.
- **상단 60% 추상도형:** 모노크롬 검정 바탕, 입체감 있는 구체/도넛/분기 형태, 성긴 8×8 Bayer ordered dithering. 파일럿의 도트 간격은 720px 기준 약 10.3px, 1080px 환산 약 15.45px.
- **유한하고 결정적인 움직임:** blob → ring → branch → sphere를 의미에 따라 변형한다. 카메라에 완만한 팬/줌과 절제된 스프링을 쓸 수 있으나, 텍스트는 움직이는 도형과 분리해서 선명하고 안정적으로 유지한다. 독립 난수 깜박임이나 무한 루프 금지.
- **정보성 서사:** 질문 → 맥락 → 대비 → 전환 → 결론 회수. `~합니다/~입니다` 자연스러운 한국어, 장면당 하나의 역할, 실제 TTS 음성 타임스탬프로 컷/자막 타이밍을 맞춘다.
- **커버:** 결론을 선공개하지 않는다. 파일럿 질문 `내 책임은 어디까지일까요?`를 중앙 그리드에서 읽을 수 있게 배치한다. 브랜드 장식은 크롭 밖에 있어도 무방하다.
- **공통 CTA:** 본문 결론을 마친 후 기존 프로덕션 파이프라인에서 별도 삽입한다. 파일럿에 CTA가 없다는 이유로 본문 결론을 없애지 않는다.

`pilot-layout.json`은 이 파일럿의 **9개 장면 제목/보조 자막 측정 영역 및 커버 중요 텍스트 3개 측정 영역**을 1080px 좌표로 저장한 스냅샷이다. 새 영상은 새 타이포 실측값으로 갱신해야 한다. 단일 측정 검사는 모든 모션 중간 프레임이나 플랫폼 UI를 자동 검증하지 않는다.

실제 완성 전에는 긴 한글 문장, 전환의 초기/중간/종료 프레임, 휴대폰 크롭, 전체 오디오 트랙의 재생 여부를 확인한다. 로컬 파일럿 영상은 720×1280·30fps로 출력했지만, 프로덕션 정식 릴스는 기존 1080×1920·30fps 정책을 따른다.

기존 `style.safeArea = "shorts-reels"`을 유지한 채 이 검수 프로필을 사용한다. **렌더러·템플릿 레지스트리·워크플로우 옵션·테스트를 함께 구현하기 전에는 새 template ID를 등록하지 않는다.**


## 나레이션 및 음질 기준 — 파일럿 회고

최초 파일럿은 **원본 음성을 합성하는 과정에서 임시 음원을 약 6.5kbps Opus로 압축**해 심한 품질 열화가 발생했다. 최종 MP4를 AAC 128kbps로 재인코딩해도 중간 압축에서 잃은 정보는 복구되지 않는다.

**필수 품질 게이트:**

1. TTS 원본 WAV/PCM 또는 원본 API 음원을 우선 사용하고 캐시한다. 불필요한 재압축을 하지 않는다.
2. 음성 전달 과정에서 손실 압축이 불가피하다면 **Opus 최소 96kbps, 파일럿 권장 128kbps 이상**으로 유지한다. 6.5kbps 같은 초저비트레이트 중간 음원은 실패 처리한다.
3. 최종 배포 MP4에는 오디오 트랙을 직접 포함하고 **AAC 160kbps 이상(권장 192kbps), 48kHz**로 인코딩한다. 원본 모노 음성을 의미 없이 스테레오로 확장하지 않는다.
4. `ffprobe`로 포맷/샘플레이트/트랙 유무/길이를 확인한다. `ffmpeg`로 처음·중간·끝 음성을 실제 디코드해 무음/깨짐/클리핑 여부를 듣고 검수한다. 메타데이터 검증만으로 음질 합격을 선언하지 않는다.
5. 영상 끝의 음성 잘림을 방지한다. 오디오 시작 오프셋과 자막/씬 전환 타이밍을 실제 음성 길이에 맞추고 부족한 끝 부분은 짧은 무음 패딩으로 채운다. 보이스오버가 영상보다 길면 실패 처리한다.
6. 게시용 결과물은 **단일 MP4**다. 무음 GIF, 외부 음성 URL이 필요한 HTML 플레이어로 대체하지 않는다.

파일럿 기준: 영상 34.5초 / 720×1280 / 30fps, 내레이션 원본 약 33.6초·48kHz 모노 WAV. 수정본은 전달 중간 음원 128kbps Opus → 최종 오디오 약 189kbps AAC 48kHz 모노이며, **원본 WAV를 직접 복사한 무손실 경로는 아니다**.

검증 예:

```bash
ffprobe -v error -show_entries stream=codec_name,codec_type,bit_rate,sample_rate,channels -show_entries format=duration -of json final.mp4
ffmpeg -v error -i final.mp4 -map 0:a:0 -t 5 -f null -
```

## HyperFrames 릴스 고정 프리셋 — 2026-11-11

[hyperframes-reel-preset.json](hyperframes-reel-preset.json)은 새 **수동 제작 릴스에서 우선 재사용할 프리셋**을 기록한다. 「추정 해상도 향상 기법」 릴스의 HyperFrames 버전을 기준으로 아래 사항을 고정한다.

- **목소리**: 한국어 HeyGen Voice `Velvet Scholar` (`voice_id=9f774d1a93b84a26aa3da3cf5ddf6135`). 해당 음성이 활성화되어 있고 무료 허용량 내일 때 우선 사용한다. 무료 MCP의 `heygen-voice-1-turbo-free`는 일일/서비스 한도가 있으므로 **영구 무료·무제한이라고 가정하지 않는다**. 비용 발생 가능 시 무단으로 유료 전환하거나 다른 음성으로 바꾸지 않고, 대체 무료/로컬 한국어 TTS를 명시해 선택한다.
- **그림과 모션**: HyperFrames + seekable HTML/CSS/GSAP, 어두운 모노크롬, 위쪽의 의미 있는 Bayer 8×8 디더링 오브젝트와 큰 숫자·주요 구간 그래프에만 디더링 적용. 본문 한글·눈금·라벨은 선명하게 유지한다.
- **한글/안전영역**: Pretendard, 도형 스테이지와 타이포 영역 분리. 표·숫자·눈금 간 겹침, 사각형 넘침을 허용하지 않는다. 1080×1920에서 핵심 문구 `x=96..920, y=270..1530`, 커버의 4:5 크롭을 별도 점검한다.
- **설명형 SNS 캡션**: 일화의 반복이나 내레이션 전사가 아니라 기법의 정의·활용법·짧은 예제·종료 기준·한계를 독자가 바로 적용할 수 있게 설명한다.
- **품질 게이트**: HyperFrames `lint`, `check`, 씬·전환 구간 `snapshot`, 글자 실측, 48kHz AAC 오디오 트랙/음량 확인 후 음성과 영상이 합쳐진 MP4를 전달한다.

**적용 범위 주의:** 이 JSON은 후속 제작 시 참조할 명시적 기본값이며, 현재 `src/templates/registry.ts`에 등록된 자동 렌더링 템플릿도 아니고 GitHub Actions가 자동으로 HeyGen TTS를 호출하는 기능도 아니다. 자동 적용을 원한다면 렌더러·설정 로더·시크릿/비용·CI를 별도로 구현하고 검증해야 한다.

## 동적 디더링 회고 및 필수 구현 원칙 — 2026-11-11

**기존 HyperFrames 릴스의 문제:** 디더링은 적용됐지만, 미리 계산된 도트 구체·숫자·그래프를 이동/확대/크롭하는 **정적 이미지 디더링**에 가까웠다. 도트가 명암 변화에 반응하지 않아 효과가 평평하게 보였다.

**새 기준:** [동적 디더링 구현 명세](dynamic-dithering.md)를 따른다.

- **그라데이션 우선:** 구체·링·브랜치의 광원, 하이라이트, 그림자, 알파 전이를 적극적으로 움직여 연속 톤이 달라지게 한다. 단색 오브젝트에 도트만 붙이는 방식은 피한다.
- **렌더 시점 재계산:** 원본 형태/명암을 `t`에서 만든 뒤, 최종 출력 좌표계에서 Bayer ordered-dithering을 **프레임마다 다시 적용**한다. 정적 디더링 PNG/SVG/CSS 점 무늬를 움직이는 것만으로는 불합격이다.
- **권장 구현:** HyperFrames에서 결정적인 `render(t)` 기반 Canvas/OffscreenCanvas 또는 WebGL shader. `seek(t)` 재생 시 동일 시점은 동일 결과여야 하며 임의 깜박임은 금지한다.
- **중요 정보 분리:** 큰 숫자·주요 구간 그래프에는 동적 디더링을 활용하되, 설명 한글·작은 숫자·눈금·자막은 마지막에 선명하게 합성한다. 기존 안전마진과 박스 넘침 금지 규칙은 그대로 유지한다.
- **검수:** 정지된 화면 좌표에서도 광원/그라데이션 변화에 따라 도트 밀도·분포가 달라지는 프레임을 비교한다. 단순 크롭·확대/이동만 보이면 실패 처리한다.

이 원칙은 **후속 제작의 기준을 저장한 것**이다. 기존 영상의 렌더 결과나 `shorts/scripts/build-hyperframes.mjs`에 동적 디더링 필터가 자동 적용된 상태는 아니다. 실제 적용에는 별도 렌더 프리미티브와 테스트/컴파일러 연결이 필요하다.
