# 숏츠 후보 스토리보드

각 후보의 스토리보드를 열어 대본, 화면 구성, 도식의 변화, 자막 리듬을 검토하세요. 원본 JSON을 수정한 경우 이 문서도 다시 생성해야 합니다.

## candidate-01 · 자동화보다 어려운 것: 무엇을 맡기지 않을 것인가

**첫 문장:** AI 시대의 경쟁은 프롬프트 경쟁이 아닙니다.

원문의 ‘위임전쟁’을 글쓰기 밖의 일로 확장한다. 1~6장 ‘프롬프트보다 위임 경계’, 7~12장 ‘개발과 이력서에서의 판단’, 13~18장 ‘Human in the loop의 정체’로 구성한다. 앞선 후보들과 달리 조직·개발·커리어 전반에서 책임을 남기는 능력을 중심 논지로 삼는다.

## candidate-02 · 경험은 사람에게, 편집은 AI에게

**첫 문장:** AI에게 글을 맡기는 게 아니라, 편집만 맡겨야 합니다.

원문의 실천적 위임 원칙에 집중한 확장 구성이다. 1~6장 ‘원재료는 누가 만드는가’, 7~12장 ‘AI가 맡을 편집 업무’, 13~18장 ‘불완전함을 보존하는 요청법’으로 전개한다. 첫 후보의 콘텐츠 피로 원인 분석과 겹치지 않고, 실제 협업 경계와 요청 방식에 초점을 둔다.

## candidate-03 · 너무 맞아서 남지 않는 글

**첫 문장:** 틀린 말이 없는데, 왜 AI 글은 기억에 남지 않을까?

원문의 ‘AI 콘텐츠 피로’를 하나의 인과관계로 발전시킨 확장 구성이다. 1~6장 ‘거부감의 신호’, 7~12장 ‘평균으로 수렴하는 답’, 13~18장 ‘잡음이 곧 사람의 좌표’로 구성한다. 세 소주제 모두 AI 자체보다 경험의 경로가 사라지는 문제를 설명하므로 하나의 영상으로 자연스럽게 이어진다.
