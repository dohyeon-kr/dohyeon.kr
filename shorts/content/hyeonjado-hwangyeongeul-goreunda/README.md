# 숏츠 후보 스토리보드

각 후보의 스토리보드를 열어 대본, 화면 구성, 도식의 변화, 자막 리듬을 검토하세요. 원본 JSON을 수정한 경우 이 문서도 다시 생성해야 합니다.

## candidate-01 · 좋은 조언 뒤에 숨은 관리자의 불안

**첫 문장:** ‘어디서든 배워야 한다’는 조언에는 말하는 사람의 불안이 섞일 수 있다.

글 속 팀장 면담 경험만을 중심으로, 옳은 조언도 화자의 이해관계를 가릴 수 있다는 독립 논점을 추출한다.

## candidate-02 · 가장 똑똑하다면, 정말 그 방을 나와야 할까?

**첫 문장:** “내가 가장 똑똑한 사람이라면, 그 방을 나와라.”

인용 → 의문 → 배움의 구체적 사례 → 방의 의미 질문 → 혼자 성장을 떠맡는 상황 → 환경의 역할 → 해석 → 배움의 지속 여부를 묻는 결론으로 이어간다.

## candidate-03 · 환경은 생각과 행동의 기본값을 만든다

**첫 문장:** 당신의 생각은 의지보다 주변 사람에게 더 자주 교정된다.

환경이 사람을 바꾼다는 주장을 ‘사람→기준, 문화→범위, 반복된 말→세계관’이라는 세 경로로 좁혀 설명한다.
