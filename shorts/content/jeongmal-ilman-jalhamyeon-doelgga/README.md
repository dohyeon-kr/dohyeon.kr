# 숏츠 후보 스토리보드

각 후보의 스토리보드를 열어 대본, 화면 구성, 도식의 변화, 자막 리듬을 검토하세요. 원본 JSON을 수정한 경우 이 문서도 다시 생성해야 합니다.

## candidate-01 · 정말 일만 잘하면 될까?

**첫 문장:** 정말 일만 잘하면 될까요?

총 19페이지(본문 18 + 공통 CTA 1)의 단일 서사입니다. 기 1–4: 능력의 순위와 높은 지위·보상이 일치하는지 묻습니다. 승 5–10: 큰 권한을 맡기는 기준에서 신뢰와 함께 겪은 경험으로 이어집니다. 전 11–16: 신뢰는 보이지 않고 성적·자격증은 확인하기 쉬워 공부에 노력이 쏠리지만, 조직과 동료의 인정은 함께하는 시간에서 만들어진다는 대비를 세웁니다. 같이 일하고 싶은 감각의 구체적인 경험을 쌓습니다. 결 17–18: 능력 이상으로 신뢰에 두는 가치에서 권한·인정·보상으로 도입 질문을 회수합니다. 19: 공통 CTA. 기존 17페이지를 삭제하고 즐겁고 싶다는 동기 해설은 제외했습니다. 함께 웃었던 기억은 협업 경험의 일부로만 남깁니다. 기존 사진과 도식을 유지하며 실제 재생 시간은 TTS 생성 후 확정합니다.
