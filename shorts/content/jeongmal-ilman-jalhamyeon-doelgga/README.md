# 숏츠 후보 스토리보드

각 후보의 스토리보드를 열어 대본, 화면 구성, 도식의 변화, 자막 리듬을 검토하세요. 원본 JSON을 수정한 경우 이 문서도 다시 생성해야 합니다.

## candidate-01 · 정말 일만 잘하면 될까?

**첫 문장:** 정말 일만 잘하면 될까요?

기존 세 후보를 이어 붙이지 않고 처음부터 쓴 단일 서사입니다. 총 20페이지(본문 19 + 공통 CTA 1)로 21페이지 이내입니다. 기 1–4: 능력과 보상의 기대에 의문을 만듭니다. 승 5–10: 조직이 맡기는 책임과 함께한 경험을 거쳐 8페이지에서 신뢰를 명명합니다. 전 11–16: 측정하기 어려운 경험을 놓치는 성장 방식에서, 같이 보내는 시간의 질과 복합적인 동행의 감각으로 이동합니다. 결 17–19: 조직을 윤택하게 만드는 능력을 인정하고 도입 질문을 회수해 함께 만드는 시간의 질로 답합니다. 20: 공통 CTA. 군대·국가별 채용·AI 대체로 주제를 넓히지 않습니다. 사진은 페이지 의미에 맞게 새로 선정했습니다. 1/14, 5/17, 11/19의 같은 사진은 질문과 결론을 연결하는 의도적 회수입니다. 실제 재생 시간은 TTS 생성 후 확정합니다.

## 한 편의 대본

| 페이지 | 화면 핵심 | 내레이션 |
| --- | --- | --- |
| 1 | 정말 일만 잘하면 될까? | 정말 일만 잘하면 될까요? |
| 2 | 능력을 키우면 보상도 따라올까 | 능력을 키우고 좋은 성과를 내면, 인정과 보상도 따라올 거라고 생각했습니다. |
| 3 | “일만 잘하면 됐지” | 그런데 “일만 잘하면 됐지”라는 말은 왜 어딘가 부족하게 들릴까요? |
| 4 | 잘하는 일과 맡기는 자리 | 실무를 가장 잘하는 사람이 언제나 팀장이 되지는 않습니다. |
| 5 | 무엇을 먼저 선택할까 | 팀을 맡길 때는 다른 질문도 생깁니다. 자원이 부족할 때, 무엇을 먼저 선택할까요? |
| 6 | 문제가 생기면 어떻게 할까 | 문제가 생기면 숨기지 않고 알릴까요? 누가 지켜보지 않아도 합의한 방향으로 일할까요? |
| 7 | 질문이 넓어집니다 | 무엇을 할 수 있는지에 더해, 어디까지 맡길 수 있는지를 보게 됩니다. |
| 8 | 저는 그것이 신뢰라고 생각합니다 | 문제를 풀 능력, 약속을 지키는 태도, 함께 정한 방향으로 움직일 거라는 믿음. 저는 그것이 신뢰라고 생각합니다. |
| 9 | 작은 약속부터 함께한 경험까지 | 작은 약속을 지키고 어려운 일을 함께 겪으며, 사람들은 서로를 알아갑니다. |
| 10 | 점수에 없는 상황 | 점수로 확인하지 못했고, 계약에도 적어두지 않은 상황에서 그 경험이 판단의 근거가 됩니다. |
| 11 | 경험에는 점수표가 없습니다 | 그런데 이런 신뢰는 실적처럼 비교하기 어렵습니다. 잘 보이지 않는 만큼, 그 가치를 놓치기도 합니다. |
| 12 | 공부는 오늘, 사람은 나중에? | 그래서 성장하려고 공부는 더 하면서, 사람을 만나고 알아가는 일은 나중으로 미루기도 합니다. |
| 13 | 함께할 시간도 지금 필요합니다 | 책은 혼자 펼칠 수 있지만, 만남은 서로 시간을 맞춰야 합니다. 관계가 깊어질 시간도 지금의 성장 안에 필요합니다. |
| 14 | 함께한 시간은 어땠을까 | 그렇다면 저는 좋은 결과를 만드는 동안, 동료가 저와 보내는 시간도 살피고 있었을까요? |
| 15 | “같이 일하고 싶다” | 같이 일하고 싶다는 감각은 생각보다 복합적입니다. |
| 16 | 믿음과 대화, 함께 웃었던 기억 | 일을 잘한다는 믿음에, 편하게 대화했던 기억, 어려울 때 도움을 받고 함께 웃었던 시간까지 섞여 있습니다. |
| 17 | 우리 조직을 윤택하게 만드는 일 | 우리 조직을 윤택하게 만드는 능력은 중요합니다. 그리고 오래 같이 가려면, 함께 만드는 시간도 좋아야 합니다. |
| 18 | 일을 잘하는 것에서 함께하는 시간까지 | 정말 일만 잘하면 될까요? 오래 함께하고 싶다면, 같이 만드는 시간의 질에도 더 마음을 써야 합니다. |
| 19 | 사람은 다른 사람과 즐겁고 싶으니까요 | 저는 그게 더 본질적이라고 생각합니다. 결국 사람은 다른 사람과 즐겁고 싶을 뿐이니까요. |
| 20 | 공통 CTA | 더 자세한 이야기는 블로그에 정리했습니다. 프로필 링크에서 읽어보세요. |

사진의 출처와 라이선스는 JSON 및 상세 스토리보드에 기록했습니다. 로컬 환경에서 사진 CDN 요청이 403으로 차단되어 실제 사진 크롭과 렌더 프레임 검수는 아직 완료하지 못했습니다. 스키마·도식 배치·자막과 대본 일치 검증은 통과했습니다.
