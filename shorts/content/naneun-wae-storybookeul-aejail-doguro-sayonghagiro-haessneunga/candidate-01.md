# 애자일은 언제 보여주느냐

**템플릿:** Notebook Grid · 가벼운 에세이 (notebook-grid)

원본: [candidate-01.json](candidate-01.json)

JSON에서 자동 생성한 검토용 스토리보드입니다. 수정은 원본 JSON에 반영한 뒤 다시 생성하세요. 연출 설명은 기획 의도이며, 실제 배치·동작은 렌더된 스냅샷과 영상으로 확인합니다. 음성 생성 전이므로 재생 시간은 확정하지 않습니다.

**첫 문장:** 티켓을 하루 단위로 나눠도, 동료가 2주 뒤에야 화면을 본다면, 빠른 피드백이라고 할 수 있을까요?

**기획 의도:** 피드백 시점과 같은 화면·조건을 공유하는 협업 구조에 집중한 원문 기반 후보. 다른 후보와 독립적인 질문과 답으로 구성했다. 정적 도식 재사용은 동일한 관계를 이어 설명하기 위한 의도적인 선택이다.

## 1. 도입 — 매일 끝나는 티켓 2주 뒤 보는 화면

**내레이션**

- 주 문구: 매일 끝나는 티켓 2주 뒤 보는 화면
