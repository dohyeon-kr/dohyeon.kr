# 숏츠 후보 스토리보드

각 후보의 스토리보드를 열어 대본, 화면 구성, 도식의 변화, 자막 리듬을 검토하세요. 원본 JSON을 수정한 경우 이 문서도 다시 생성해야 합니다.

## candidate-01 · 프로는 난도를 낮추는 사람이다

**첫 문장:** 프로는 어려운 일을 잘하는 사람일까요?

원문의 최종 정의인 ‘어려운 일을 잘할 수 있는 일로 만드는 것’을 중심으로 구성한다. 체력·사고력도 돈과 시간처럼 관리해야 하는 리소스라는 근거를 쌓고, 적시에 도구와 단순화를 선택하는 능력으로 프로페셔널함을 재정의한다.

## candidate-02 · 뇌를 저장소로 쓰지 않는 법

**첫 문장:** 기억하면서 일하는 건, 집중이 아닐 수 있습니다.

아이디어·계산·할 일을 머릿속에 유지하는 부담과 메모·문서·계산기를 통한 외부화에 집중한다. 멀티태스킹처럼 느껴지는 상태를 빠른 왕복으로 재정의하고, 뇌에는 저장보다 한 가지 사고를 맡기자는 독립 논지다.

## candidate-03 · 미래를 다 대비하면 현재가 복잡해진다

**첫 문장:** 12px 하나에, 어디까지 대비해야 할까요?

원문의 12px 사례에 집중한 후보다. 기술 부채를 피하려는 선의가 어떻게 불필요한 설계와 피로로 이어지는지 보여주고, 현재 명확한 정보에 맞춰 결정하자는 결론으로 회수한다. 다른 후보의 기억 외부화·프로의 정의와 겹치지 않는다.
