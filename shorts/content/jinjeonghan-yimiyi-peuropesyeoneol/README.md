# 숏츠 후보 스토리보드

각 후보의 스토리보드를 열어 대본, 화면 구성, 도식의 변화, 자막 리듬을 검토하세요. 원본 JSON을 수정한 경우 이 문서도 다시 생성해야 합니다.

## candidate-01 · 프로는 난도를 낮추는 사람이다

**첫 문장:** 프로는 어려운 일을 어떻게 해낼까요?

기존 세 후보를 하나의 논지로 통합했다. 1~3장은 프로의 기준과 유한한 자원, 4~7장은 기억의 외부화와 작업 분해, 8~13장은 불필요한 미래 대비의 부담, 14장은 도입 질문을 회수하는 결론이다. 장보기·집 정리·여행을 설명용 비유로 사용하며 원문의 실제 경험이나 연구 결과로 주장하지 않는다. 불필요한 브릿지와 1인칭을 덜어 본문 14장과 공통 CTA 1장으로 구성했다. 발표자는 본문 1~14장의 우측 하단에 표시하며 최종 TTS 단어 타임스탬프에 맞춘 입 움직임과 노딩을 사용한다. 15장 공통 CTA에서는 숨긴다.
