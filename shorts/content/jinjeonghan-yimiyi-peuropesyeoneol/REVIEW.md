# 통합 후보 검수

대상: [candidate-01.json](candidate-01.json), 본문 14장 + 공통 블로그 CTA 1장.

## 편집 및 시각 선택

- 프로의 기준 → 기억의 외부화 → 불필요한 미래 대비 → 결론으로 연결한다. 장보기·집 정리·여행은 설명용 비유이며 원문의 실제 경험이나 연구 결과로 주장하지 않는다.
- 수사법은 도입 질문과 결말의 핵심어 회수, 짐의 비유, 필요한 곳의 대구에 한정한다. 1인칭·픽셀 계산·불필요한 연결용 질문을 제거했다.
- 사진 2장: 4장(장보기), 9장(여행 준비). 모두 풀블리드이며 크롭에서 장바구니와 여행 가방이 보이는지 확인했다. 인물의 실제 생각·행동에 대한 평가가 아닌 상황 예시다.
- 도식은 분해·이동·누적·조건별 분류를 설명한다. 아이콘 fallback은 없다. 라벨은 도형 위, 자막과 발표자는 별도 영역에 둔다.
- 최상위 `presenterOverlay`를 지원하는 렌더 코드를 함께 추가했다. 발표자는 모든 장면과 CTA에서 우측 하단에 고정되며 전환 효과 밖에 한 번만 렌더한다. 기본 표정·깜빡임·선화 움직임을 사용한다.

## 검증

- 타입 검사 통과.
- 발표자·통합 후보 관련 테스트 24개 통과. 장면 스키마, 자막과 내레이션 일치, 도식 중간 상태, CTA 중복 방지와 overlay 보존을 포함한다.
- 레이아웃·전환·스토리보드 리뷰·로드 관련 테스트 38개 통과.
- 전체 테스트는 127개 중 126개 통과. 로컬에 ffmpeg가 없어 기존 video-background의 실제 디코딩 테스트 1개가 `spawnSync ffmpeg ENOENT`로 실행되지 못했다. 해당 테스트의 성공을 주장하지 않는다.
- 1080×1920 무음 영상 1,827프레임을 렌더했다. 실제 렌더 시 도식 및 한글 영역 검사와 발표자 충돌 검사를 통과했다. 최초 검수에서 제목 진입 동작의 충돌을 발견해 발표자 모드의 제목 여백을 확보한 뒤 전체를 다시 렌더했다.
- 주 렌더 테마의 15장 결과 화면과 14개 전환의 시작·중간·끝(42프레임)을 별도로 출력했다. 전환 시 발표자가 사라지거나 함께 흐려지지 않는지, 한글과 사진의 주요 피사체를 가리지 않는지 확인했다.
- 보조 렌더 테마에서도 같은 57개 시점의 프레임을 출력해 발표자와 제목·자막 예약 영역의 충돌 검사를 통과했다.
- 실제 음성 생성·립싱크·최종 낭독 속도는 미검증이다. 무음 프리뷰의 약 61초는 임시 검토 타이밍이며 최종 영상 길이가 아니다. 유료 TTS와 최종 영상 발행은 실행하지 않았다.
