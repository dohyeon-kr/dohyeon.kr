# 미래를 다 대비하면 현재가 복잡해진다

원본: [candidate-03.json](candidate-03.json)

JSON에서 자동 생성한 검토용 스토리보드입니다. 수정은 원본 JSON에 반영한 뒤 다시 생성하세요. 연출 설명은 기획 의도이며, 실제 배치·동작은 렌더된 스냅샷과 영상으로 확인합니다. 음성 생성 전이므로 재생 시간은 확정하지 않습니다.

**첫 문장:** 12px 하나에, 어디까지 대비해야 할까요?

**기획 의도:** 원문의 12px 사례에 집중한 후보다. 기술 부채를 피하려는 선의가 어떻게 불필요한 설계와 피로로 이어지는지 보여주고, 현재 명확한 정보에 맞춰 결정하자는 결론으로 회수한다. 다른 후보의 기억 외부화·프로의 정의와 겹치지 않는다.

**원문:** [진정한 의미의 프로페셔널](<https://blog.dohyeon.kr/jinjeonghan-yimiyi-peuropesyeoneol/>)

## 2. 사진 — 요구는 하나, 준비는 계속 늘어난다

**화면 구성**

- 주 문구: 요구는 하나, 준비는 계속 늘어난다
- 배치: 도식을 중앙에 배치
- 전달할 관계: 현재 요구 하나가 여러 미래 대비 작업으로 증식한다.
- 표현 방식: 공간 도식 — 작은 명세에서 뻗어 나오는 설계 가지
- 표현 이유: 아이콘보다 작업 단계가 실제로 늘어나는 관계를 직접 보여준다.
- 도식 구성: 사각형 ‘12px 명세’, 사각형 ‘rem 변환’, 사각형 ‘루트 설정’, 사각형 ‘변수화’, 선, 선, 선, 선

**연출 흐름**

- 시작: 중앙에 명세 12px만 보인다.
- 사건: 미래의 화면과 재사용 가능성을 미리 고려한다.
- 변화: rem, 루트 설정, 변수 노드가 연속해서 추가된다.
- 유지: 원래 요구사항은 12px 텍스트 하나로 유지된다.
- 결과: 작은 요구보다 준비 과정이 더 큰 구조가 된다.

## 3. 비교 — 미래의 변수가 현재를 잠식한다

**내레이션**

문제는 완벽성 자체가 아닙니다. 아직 존재하지 않는 변수를 현재 일로 끌어오는 게 문제입니다.

**화면 구성**

- 주 문구: 미래의 변수가 현재를 잠식한다
- 배치: 도식을 중앙에 배치
- 전달할 관계: 고려할 미지수가 현재 업무 공간 위로 누적된다.
- 표현 방식: 공간 도식 — 현재를 잠식하는 미래 영역
- 표현 이유: 영역의 실제 확장으로 불필요한 고려가 차지하는 범위를 명확히 보여준다.
- 도식 구성: 사각형 ‘현재 작업’, 사각형 ‘불확실한 미래’

**연출 흐름**

- 시작: 현재 작업 상자와 불확실한 미래 영역이 분리되어 있다.
- 사건: 모든 미래 조건을 현재 작업으로 끌어온다.
- 변화: 현재 작업 영역이 넓어지고 미래 영역과 중첩된다.
- 유지: 실제로 확정된 요구는 작은 현재 상자 안에만 있다.
- 결과: 불확실성이 현재의 복잡성을 차지한다.

2. 시각 요소의 변화 진행
3. 핵심 부분에 시선 집중
