# 페이지 영상 배경 제작 가이드

등록 소스의 풀블리드 영상 배경을 생성·리뷰·스토리보드·최종 렌더에서 지원한다. 공통 기준은 [creative-system.md](creative-system.md#영상-배경-선택과-연출)이다.

## 장면 선택

| 장면 목적 | 권장 배경과 합성 | 피할 방식 |
| --- | --- | --- |
| 도입의 질문 | 천천히 열리는 문 풀블리드, 비어 있는 면에 질문 등장 | 문 아이콘 대체, 문 여는 동작 반복 |
| 경험·공간·정서 | 빈 방의 미세한 빛 변화, 낮은 채도와 짧은 문장 | 맥락 없는 화려한 스톡 영상 |
| 설명 | 움직임이 적은 샷, 텍스트 영역에 국소 오버레이 | 피사체가 글자 뒤를 계속 통과 |
| 복잡한 그래프·도식 | 정적 배경 또는 승인된 정지 프레임 | 배경 이동·그래프 변화·자막 확대 동시 진행 |
| 마무리 | 논지와 연결되는 여운 있는 샷, 결론을 읽을 시간 확보 | 결론이 나오자마자 컷 종료 |

매체 선택은 의미에 따른다. 같은 영상의 반복 사용과 최근 릴스 도입부 재사용을 원본 URL/ID 기준으로 확인한다. 의도된 연결 장면은 사용 이유를 기록한다.

## 스토리보드 편집 명세

다음 표는 편집 검토 항목이다. 실행 JSON은 아래 지원 형식을 사용하며 미확보 소스와 타임코드를 만들어 넣지 않는다.

| 항목 | 작성 내용 |
| --- | --- |
| 목적·상태 | 영상이 필요한 이유, 제안/소스 확보/구현/렌더 검수 상태 |
| 소스 | 원출처 페이지, 제작자, 라이선스와 확인 근거, 원본 ID, 확보한 파일 경로 |
| 사용 구간 | 원본 시작·끝 초, 원본 길이, 재생 속도, 장면 목표 길이 |
| 길이 대응 | 반복 여부, 이음새 처리 또는 승인된 정지 프레임 유지; 부족 시 다른 구간/소스 선택 |
| 배치 | 풀블리드/분할, 9:16 크롭의 기준 피사체, 전체 구간의 이동 범위 |
| 가독성 | 명암·채도, 오버레이 위치/농도, 제목·도식·자막 예약 영역 |
| 타이밍 | 배경의 주요 사건과 텍스트 등장·강조 시점, 결과를 읽는 유지 시간 |
| 오디오 | 기본 음소거, 현장음 사용 시 목적과 내레이션/BGM과의 관계 |
| 검수 | 확인한 프레임·재생 구간, 밝기·크롭·경계·오디오 결과와 미확인 사항 |

예: “방을 나온다는 것은?” 장면은 문이 한 번 천천히 열리는 샷을 검토한다. 문과 손잡이는 9:16 안에 유지하고 질문은 비어 있는 벽 쪽에 놓는다. 문이 크게 움직이는 순간에는 별도 도식 강조를 넣지 않는다. 원음은 음소거하고 추가 카메라 줌은 사용하지 않는다. 소스와 길이를 확보하기 전에는 실제 타임코드를 만들어 쓰지 않는다.

적합한 등록 소스가 없는 후보에는 실제 렌더할 사진 등 기존 표현을 지정한다. rationale에 “영상 배경 제안·소스 미확보: 문이 한 번 열리는 샷. 현재 후보는 문 사진으로 렌더”처럼 구분한다. 이 메모는 재생 명령이 아니다. 사람이 읽는 후보 Markdown에도 제안과 실제 표현이 구분되는지 확인한다.

## 구현·운영 경로

1. 후보 스키마·검증·읽기용 Markdown에 영상 소스와 편집 명세를 함께 지원한다. 사진 URL 필드에 MP4를 넣는 방식으로 우회하지 않는다.
2. 에셋 준비 단계에서 다운로드·디코딩·길이·해상도를 확인하고 렌더에 사용할 파일과 출처를 보존한다. 만료되는 스트리밍 URL에만 의존하지 않는다. 최종 1080×1920 크롭에서 화질을 확인한다.
3. 장면 로컬 시간으로 프레임을 선택해 탐색·병렬 렌더와 재렌더 결과를 재현한다. 전역 시간이나 브라우저 자동재생 상태에 의존하지 않는다.
4. 스토리보드와 최종 합성에 같은 크롭·오버레이·레이어·구간 설정을 적용한다. 실제 TTS 길이가 정해지면 끝 구간·루프·유지 시간을 다시 검증한다.
5. 파일 누락·디코딩 실패·범위를 벗어난 구간은 장면과 원인을 보고한다. 대체 사진/정지 프레임은 명시적으로 선택하고 검토한 경우에만 사용한다.

## 검수와 승인

- 소스: 실제 파일 재생, 원출처·라이선스, 중복 사용, 사용 구간과 길이 확인.
- 프레임: 시작·중간·끝뿐 아니라 가장 밝은 순간, 피사체 최대 이동, 텍스트 등장 중간, 최대 점유 상태에서 한글 받침·보호 여백·플랫폼 UI 영역 확인.
- 재생: 루프 이음새와 전환 전후의 검은 프레임·튐·의도하지 않은 정지·반복 행동 확인. 휴대폰 크기로 전체 장면을 재생해 시선 분산 확인.
- 최종 음성 포함 영상: 내레이션·자막·배경 사건의 동기와 현장음/BGM 충돌 확인. 대표 PNG나 무음 미리보기만 보고 오디오 또는 전체 모션 통과라 하지 않음.
- 소스·구간·크롭·속도·오버레이·장면 길이가 바뀌면 영향을 받는 장면과 전환을 다시 검토.


## 실행 형식

장면의 `backgroundVideo`가 없거나 null이면 기존 표현을 그대로 렌더한다. 배경 영상과 `visual.type=photo`/image를 함께 지정하지 않는다. 도식이나 문장은 전경으로 합성할 수 있다. 추가 카메라는 static이다.

```json
"backgroundVideo": {
  "assetId": "teluk-prancis-waves",
  "startSeconds": 1,
  "endSeconds": 6,
  "playbackRate": 1,
  "endBehavior": "error",
  "cropX": 0.5,
  "cropY": 0.5,
  "overlayOpacity": 0.4
}
```

- cropX/Y는 0~1의 object-position이다. 영상은 풀블리드 cover 크롭·흑백·어두운 그라데이션으로 합성한다. 분할 배경과 원음 합성은 현재 지원하지 않는다.
- endBehavior는 error 또는 loop. error는 실제 장면 길이(내레이션+0.28초, 최소 2.2초)를 채우지 못하면 중단한다. loop는 선택 구간만 반복한다. 자동 이음새 보정이나 끝 프레임 고정은 하지 않는다.
- 에셋 단계에서 선택 구간과 속도를 적용한 무음 30fps MP4를 생성한다. 원본 오디오는 제거한다. OffthreadVideo가 장면 로컬 프레임을 읽고 전환 중 이전 장면은 기존 Freeze 정책에 따라 마지막 프레임을 유지한다.
- 스토리보드의 initial/change/result는 장면의 20/50/80% 표본이며 첫/마지막 프레임이나 최대 밝기를 보장하지 않는다. 최종 길이 변화 후 별도 재검수한다.
- 원본 SHA-256과 실측 길이·해상도, 모든 프레임의 디코딩을 검사한다. 다운로드 최대 100MiB, 원본 최대 600초, 크롭 시 최대 2배 확대 해상도, HTTPS 직접 파일 URL만 허용하며 리다이렉트는 거절한다. 로컬 캐시가 손상되거나 새 다운로드가 해시와 다르면 중단한다.
- `*-VIDEO.md`와 최종 `*-MEDIA.md`에 출처·제작자·라이선스·해시·사용 구간·변경 사항을 남긴다. AI 리뷰는 표본 프레임 검토이며 연속 재생이나 오디오 검수가 아니다.

## 소스 등록

`shorts/media/videos.json`은 편집자가 검토하는 소스 목록이다. AI에는 이 목록을 전달하며 임의 다운로드 URL 대신 assetId를 선택하게 한다. 적합한 소스가 없으면 먼저 등록한다. 웹 전체의 자동 스톡 검색은 제공하지 않는다.

메타데이터 JSON에 id, title, description(내용과 적합한 장면), creator, sourcePage, downloadUrl, license, licenseUrl을 작성한 뒤 실행한다.

```sh
node shorts/scripts/register-video.mjs /path/to/source-metadata.json
```

도구가 파일을 내려받아 실제 길이·해상도·SHA-256을 기록한다. 메타데이터를 작성할 때 원출처와 라이선스 페이지를 직접 확인한다. 목록 JSON은 저장소에 커밋하고 원본은 CI에서 해시로 검증해 다시 확보한다. 다운로드 URL이 만료되면 같은 파일의 안정적인 직접 URL로 갱신한다.

포함된 파도 샘플은 Fandy Aprianto Rohman의 [Azure Waves at Teluk Prancis Beach (2)](https://commons.wikimedia.org/wiki/File:Azure_Waves_at_Teluk_Prancis_Beach_(2).webm), CC BY-SA 4.0이다. 샘플 변형본도 같은 라이선스로 제공하며 자르기·속도·흑백·텍스트 합성을 변경 사항으로 기록한다. 게시 시 출처·라이선스와 동일조건 공유 의무를 반영한다. 해당 영상은 자연·휴식 예시용이며 다른 주제에 자동으로 끼워 넣지 않는다.

## 재현 검증

```sh
cd shorts
npm test
npm run typecheck
node scripts/verify-video-render.mjs
```

FFmpeg/ffprobe가 PATH에 필요하다(또는 FFMPEG_PATH/FFPROBE_PATH). 검증은 유료 AI/TTS를 호출하지 않는다. 실제 샘플로 1080×1920 MP4와 반복·전환 경계 PNG를 out/video-background에 만든다. 원음 제거와 움직임·반복은 테스트로 확인하고, 제목/한글 받침·크롭·이음새의 시각적 품질은 출력물을 검토한다. 실제 후보의 내레이션 타이밍까지 검증한 결과로 해석하지 않는다.
