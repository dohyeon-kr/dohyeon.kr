# 페이지 영상 배경 제작 가이드

현재는 연출·구현 준비 가이드다. 후보 생성 스키마와 렌더 경로에 영상 배경 지원을 추가하기 전에는 아래 편집 명세를 실행용 JSON으로 사용하지 않는다. 공통 기준은 [creative-system.md](creative-system.md#영상-배경-선택과-연출)이다.

## 장면 선택

| 장면 목적 | 권장 배경과 합성 | 피할 방식 |
| --- | --- | --- |
| 도입의 질문 | 천천히 열리는 문 풀블리드, 비어 있는 면에 질문 등장 | 문 아이콘 대체, 문 여는 동작 반복 |
| 경험·공간·정서 | 빈 방의 미세한 빛 변화, 낮은 채도와 짧은 문장 | 맥락 없는 화려한 스톡 영상 |
| 설명 | 움직임이 적은 샷, 텍스트 영역에 국소 오버레이 | 피사체가 글자 뒤를 계속 통과 |
| 복잡한 그래프·도식 | 정적 배경 또는 승인된 정지 프레임 | 배경 이동·그래프 변화·자막 확대 동시 진행 |
| 마무리 | 논지와 연결되는 여운 있는 샷, 결론을 읽을 시간 확보 | 결론이 나오자마자 컷 종료 |

매체 선택은 의미에 따른다. 같은 영상의 반복 사용과 최근 릴스 도입부 재사용을 원본 URL/ID 기준으로 확인한다. 의도된 연결 장면은 사용 이유를 기록한다.

## 스토리보드 편집 명세

다음 항목은 검토 문서에 기록할 항목이며 현재 JSON 필드명이 아니다. 미확보 값은 미확보로 남긴다.

| 항목 | 작성 내용 |
| --- | --- |
| 목적·상태 | 영상이 필요한 이유, 제안/소스 확보/구현/렌더 검수 상태 |
| 소스 | 원출처 페이지, 제작자, 라이선스와 확인 근거, 원본 ID, 확보한 파일 경로 |
| 사용 구간 | 원본 시작·끝 초, 원본 길이, 재생 속도, 장면 목표 길이 |
| 길이 대응 | 반복 여부, 이음새 처리 또는 승인된 정지 프레임 유지; 부족 시 다른 구간/소스 선택 |
| 배치 | 풀블리드/분할, 9:16 크롭의 기준 피사체, 전체 구간의 이동 범위 |
| 가독성 | 명암·채도, 오버레이 위치/농도, 제목·도식·자막 예약 영역 |
| 타이밍 | 배경의 주요 사건과 텍스트 등장·강조 시점, 결과를 읽는 유지 시간 |
| 오디오 | 기본 음소거, 현장음 사용 시 목적과 내레이션/BGM과의 관계 |
| 검수 | 확인한 프레임·재생 구간, 밝기·크롭·경계·오디오 결과와 미확인 사항 |

예: “방을 나온다는 것은?” 장면은 문이 한 번 천천히 열리는 샷을 검토한다. 문과 손잡이는 9:16 안에 유지하고 질문은 비어 있는 벽 쪽에 놓는다. 문이 크게 움직이는 순간에는 별도 도식 강조를 넣지 않는다. 원음은 음소거하고 추가 카메라 줌은 사용하지 않는다. 소스와 길이를 확보하기 전에는 실제 타임코드를 만들어 쓰지 않는다.

지원 전 후보에는 실제 렌더할 사진 등 기존 표현을 지정한다. rationale에 “영상 배경 제안·미구현: 문이 한 번 열리는 샷. 현재 후보는 문 사진으로 렌더”처럼 구분한다. 이 메모는 재생 명령이 아니다. 사람이 읽는 후보 Markdown에도 제안과 실제 표현이 구분되는지 확인한다.

## 구현 시 연결해야 할 부분

1. 후보 스키마·검증·읽기용 Markdown에 영상 소스와 편집 명세를 함께 지원한다. 사진 URL 필드에 MP4를 넣는 방식으로 우회하지 않는다.
2. 에셋 준비 단계에서 다운로드·디코딩·길이·해상도를 확인하고 렌더에 사용할 파일과 출처를 보존한다. 만료되는 스트리밍 URL에만 의존하지 않는다. 최종 1080×1920 크롭에서 화질을 확인한다.
3. 장면 로컬 시간으로 프레임을 선택해 탐색·병렬 렌더와 재렌더 결과를 재현한다. 전역 시간이나 브라우저 자동재생 상태에 의존하지 않는다.
4. 스토리보드와 최종 합성에 같은 크롭·오버레이·레이어·구간 설정을 적용한다. 실제 TTS 길이가 정해지면 끝 구간·루프·유지 시간을 다시 검증한다.
5. 파일 누락·디코딩 실패·범위를 벗어난 구간은 장면과 원인을 보고한다. 대체 사진/정지 프레임은 명시적으로 선택하고 검토한 경우에만 사용한다.

## 검수와 승인

- 소스: 실제 파일 재생, 원출처·라이선스, 중복 사용, 사용 구간과 길이 확인.
- 프레임: 시작·중간·끝뿐 아니라 가장 밝은 순간, 피사체 최대 이동, 텍스트 등장 중간, 최대 점유 상태에서 한글 받침·보호 여백·플랫폼 UI 영역 확인.
- 재생: 루프 이음새와 전환 전후의 검은 프레임·튐·의도하지 않은 정지·반복 행동 확인. 휴대폰 크기로 전체 장면을 재생해 시선 분산 확인.
- 최종 음성 포함 영상: 내레이션·자막·배경 사건의 동기와 현장음/BGM 충돌 확인. 대표 PNG나 무음 미리보기만 보고 오디오 또는 전체 모션 통과라 하지 않음.
- 소스·구간·크롭·속도·오버레이·장면 길이가 바뀌면 영향을 받는 장면과 전환을 다시 검토.
