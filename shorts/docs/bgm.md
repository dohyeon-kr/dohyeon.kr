# BGM 운영과 후보

## 현재 구현

최종 후보 영상과 통합 템플릿 영상에 하나의 BGM을 연속으로 믹스한다. 기본값은 저장소 코드로 합성하는 **DLOG Pulse (96 BPM)**다. 외부 녹음·샘플을 가져오지 않고 킥, 하이햇, 베이스를 만든다. 이것은 고급 스톡 음원을 대체한다고 검증한 곡이 아니라 재현 가능한 기본 반주다. 음원의 독점성이나 법적 권리를 보증하는 표현은 사용하지 않는다.

Repository variable 또는 로컬 환경변수 `SHORTS_BGM_TRACK`:

| 값 | 동작 |
| --- | --- |
| 비어 있음 / `pulse-96` | DLOG Pulse, 96 BPM, 기본 미니멀 반주 |
| `grid-108` | DLOG Grid, 108 BPM, 조금 더 빠른 변주 |
| `none` | BGM 생략 |

선택값은 고정 목록으로 검증하며 임의 URL을 다운로드하지 않는다. 렌더 후 FFmpeg로 믹스하고 영상 스트림은 복사한다. 시작 0.5초, 끝 0.9초 페이드와 내레이션 타임라인 기반 덕킹을 적용한다. 실제 음성 경로가 있는 구간만 낮추며, 0.4초 미만의 짧은 쉼 사이에는 음악이 들쭉날쭉 커지지 않도록 한다. 기본 게인 0.28에서 발화 중 0.08로 낮춘다. 이는 원음 대비 게인이며 LUFS 자동 정규화나 실시간 sidechain 분석은 아니다.

자막과 영상 타이밍을 바꾸지 않는다. 전환의 비트 스냅은 아직 구현하지 않았다. 음원 길이는 영상 길이에 맞춰 합성하므로 루프 파일 끝의 이음새나 장면별 곡 교체가 없다. 제한된 기본 반주에 최종 믹스 리미터를 적용하지만 실제 TTS 발음과 음악 균형은 청취 검수가 필요하다.

`*-BGM.md`에 곡명·템포·생성 코드·믹스 방법을 남기고 Release/아티팩트에 함께 보관한다. 스토리보드 정지 이미지는 BGM을 만들지 않는다. 통합 미리보기의 `--silent`는 이제 **TTS 생략**을 뜻한다. 완전 무음 CI가 필요하면 `SHORTS_BGM_TRACK=none`도 설정한다.

## 외부 음원 후보 — 2026-09-05 조사

아래는 공식 사이트의 곡명·길이·태그를 근거로 추린 **청취 후보**다. 직접 재생을 통한 보컬 유무, 밀도, BPM, 내레이션과의 충돌은 아직 검증하지 않았다. 추천 순서는 모노크롬·전자음악·절제된 리듬이라는 제작 방향에 대한 편집 판단이다.

| 순위 | 곡 / 작가 | 길이 | 공식 분류와 선정 이유 |
| --- | --- | --- | --- |
| 1 | Hazy After Hours / Alejandro Magaña (A. M.) | 2:07 | Relaxed, Bass, Drums, Fashion, Technology. 시크한 기술·에디토리얼 무드의 첫 청취 후보 |
| 2 | Tech House vibes / Alejandro Magaña (A. M.) | 1:42 | Relaxed, Bass, Drums, Background, Intro. 리듬이 더 필요한 도식 영상용 후보 |
| 3 | Down the River / Alejandro Magaña (A. M.) | 2:13 | Chillout, Atmospheric, Relaxed, Technology. 설명과 회고 위주의 차분한 후보 |

[Mixkit Electronica 목록에서 곡명으로 찾아 재생](https://mixkit.co/free-stock-music/electronica/). [공식 음악 FAQ](https://mixkit.co/free-stock-music/)는 YouTube, 소셜미디어, 온라인 광고 등의 사용을 안내하고 크레딧은 필수가 아니라고 설명한다. CD/DVD, 게임, TV·라디오 방송은 허용 대상으로 안내하지 않는다. [Stock Music License](https://mixkit.co/license/#musicFree)를 다운로드 시점에 다시 확인하고 해당 조건을 기록한다.

외부 후보는 아직 다운로드·공개 저장소 업로드·자동 등록하지 않았다. 영상에 삽입할 수 있다는 안내만으로 원본 음원 파일을 공개 저장소에서 재배포할 수 있다고 해석하지 않는다. 선택 후 사용할 구간, 보컬 유무, 출처·다운로드 기록, 원본 보관 위치와 재배포 조건을 확인한 뒤 승인 목록과 별도 로더를 추가한다. 현재 설정의 track ID로 위 곡명을 넣을 수는 없다.
