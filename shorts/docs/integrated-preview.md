# 통합 미리보기

BGM 추가 후 `--silent`는 TTS만 생략한다. 완전 무음은 `SHORTS_BGM_TRACK=none`으로 설정한다. 아래의 기존 무음 검증 설명은 내레이션 없는 검증을 뜻한다. 곡 선택·덕킹·외부 후보는 [bgm.md](bgm.md)를 참고한다. Release에는 `*-BGM.md`도 포함된다.

`TemplatePreview`는 이제 고정 프리셋 목록이 아니라 “노력보다 먼저, 구조”라는 하나의 창작 예제다. 원문 블로그의 실제 사례나 측정 수치를 재현한 영상은 아니다.

장면 순서는 질문 → 투입/효용 그래프 → 무게로 기울어지는 시소 → 관문 앞 대기열과 해소 → 결론 → DLOG 엔딩이다. 사진이 없는 사진 커버와 라이브러리 이름을 설명하는 문구를 제거했다. 그래프·물리는 개념적 비유임을 표시한다.

- 예제의 단일 소스: `shorts/src/template-preview.ts`.
- PR CI: `render-template-preview.mjs <출력경로> --silent`. 키·유료 TTS 없이 전체 무음 영상과 여섯 장 PNG를 검증한다. 자막 시간은 추정값이다.
- 공개 Release: 같은 스크립트를 `--silent` 없이 실행한다. 기존 `OPENAI_API_KEY`, 선택적 `SHORTS_TTS_MODEL`/`SHORTS_TTS_VOICE`를 사용한다. 기본 예제에는 의미 단위 10개가 있으며 실행마다 해당 TTS 호출이 발생한다. 키가 없으면 무음 성공으로 가장하지 않고 실패한다.
- 각 의미 단위의 음성을 만든 후 길이를 ffprobe로 측정하고 지정된 쉼을 붙여 장면 음성으로 연결한다. 자막은 그 구간의 실제 시작/끝 시각을 사용한다. 이는 음성 인식에 의한 단어 단위 강제 정렬이 아니다. 짧은 음성을 이어 붙이므로 경계의 억양은 청취 검수가 필요하다.
- 영상 전체 길이와 스냅샷 위치는 동일한 장면 길이 계산을 사용한다. 고정 30초로 잘리거나 빈 꼬리가 생기지 않도록 한다.
- Release 파일: 전체 MP4, 장별 `scene-01.png`~`scene-06.png`, 기존 호환용 대표 PNG, `SCRIPT.txt`. AI 생성 음성임을 Release 설명과 스크립트에 표시한다.

모아보기 JPG와 PDF는 이 템플릿 Release에는 아직 없다. 후보 승인용 스토리보드 워크플로와는 별개다. 공개 Release 갱신은 변경사항을 main에 병합하거나 해당 워크플로를 수동 실행한 뒤 이루어진다. PR CI의 무음 영상 통과를 실제 TTS 청취 검수 완료로 해석하지 않는다.
